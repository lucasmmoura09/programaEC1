# Sistema de Loja

## Descrição
Programa simples que simula uma compra em loja.

## Lógica
O usuário escolhe um produto e quantidade.
O sistema calcula o total.
Se passar de 100 reais, aplica desconto.

## Como executar
1. Instale o Python
2. Abra o terminal na pasta do projeto
3. Execute:
python Appy.py

## Exemplo
Nome: Lucas
Produto: Camisa
Quantidade: 3
Total: 135
